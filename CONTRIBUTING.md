# Contributing to Mason

This repository is the public framework formerly called ContextOS. Keep changes
small, useful, and independently reviewable.

## Good contributions

Clearer setup instructions, portable templates, synthetic examples, reproducible
failure cases, and tested module improvements. Explain the user problem and what
your change does—not just the implementation.

## Before opening a pull request

- Use only invented examples. Do not copy and sanitize private notes or transcripts.
- Check the diff for credentials, private URLs, customer information, personal
  paths, screenshots, and hidden metadata.
- Preserve existing licensing and attribution.
- Preserve companion URLs and template placeholders unless a migration is documented.
- Check relative Markdown links and any scripts you change.
- Separate automated results from manual checks and untested device behavior.
- State whether a feature is implemented, optional, experimental, or only proposed.

Do not attach private logs or recordings to public issues. Report a suspected
credential exposure to the owner through a private channel; do not reproduce the
credential in an issue or pull request.

## Scope

App source, personal context, deployment credentials, and private acceptance
histories are outside this repository. Reflect Open changes belong in an
appropriately scoped upstream contribution, with that project's review process.

A contribution must not make a memory vendor the only durable record, grant an
agent new permissions silently, or turn every suggested idea into a task.

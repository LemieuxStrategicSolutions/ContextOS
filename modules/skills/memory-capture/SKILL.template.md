# memory-capture

**Trigger:** “capture this,” “remember this,” “save this to memory,” or `MEM:`.

## Procedure

1. Follow `memory.md` and the user's permissions. Identify the durable fact,
   decision, or insight, its source, and requested date (otherwise use {{TZ}}).
   Distinguish the user's words from AI interpretation.
2. Check owned records for duplicates. Recall from an approved connector never
   overrides current original records.
3. Save to the appropriate owned note or decision record first. Keep tasks in
   the existing tracker; never convert a suggestion into a commitment.
4. Project to an approved connector only if permitted, non-private, and
   non-excluded. Preserve the owned source reference.
5. Confirm exactly what succeeded: owned save, projection, both, or neither.
   If projection fails, keep the owned record and report the failure.

Never put secrets in notes or memory. Without a connector, use authorized owned
files. If no save path is available, return an explicitly unsaved draft.
